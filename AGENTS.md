# AGENTS.md

Guidance for AI coding agents (Claude Code, Codex and others) that work in this repository. Read [README.md](README.md) first: it describes the purpose and the layout of the repository.

For An lab members: the current version and location of the resources that several lab projects share (cohort variant lists, phenotype tables, single-cell atlases, pipelines, public references) are in the lab's shared resource index, [shared-resources.md](https://github.com/joonan-lab/wiki-manuscript/blob/main/shared-resources.md), in the private repository `joonan-lab/wiki-manuscript` (lab members only). Each row of the index points to the document of the repository that owns the resource. If this repository owns such a resource, record its versions and locations in that document, and write paths as the section "경로를 적는 방법" (how to write paths) of the index says.
